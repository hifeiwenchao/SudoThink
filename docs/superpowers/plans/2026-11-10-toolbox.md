# 工具箱实施计划

> 使用独立模块并行实现，集成后统一验证。

**目标：** 在公开导航“关于我”之前新增“工具箱”，提供时间戳、二维码、加密解密、随机数、计算器、JSON、cron 与进制转换八个工具。

**架构：** 新增 `/tools` 页面，通过 `?tool=` 保存当前工具，侧边目录在窄屏改为可滚动目录。各工具按需加载，纯函数放在 `utils/tools`，复用页面样式与复制按钮。所有输入在浏览器处理，不上传文件、明文或密钥。

**技术：** Vue 3、TypeScript、现有 Element Plus；二维码编码/识别与 cron 使用专用库。适配浅色、深色、键盘和移动端，也支持通过 IP 与 HTTP 访问。

## 全局约束

- 导航顺序为文章、动态分类、工具箱、关于我；当前项正确高亮。
- 八个模块均有可用输入、操作、输出和明确的错误信息。
- 输入内容和密钥不写入 URL、localStorage 或日志。
- 工具支持直接链接与浏览器前进/后退，切换工具不提交网络请求。
- 依赖按锁文件安装，不改动后端、数据库、管理员入口与部署配置。
- 数学表达式与 JSON 不执行 JavaScript；进制转换使用 BigInt 保持整数精度。
- 随机数数量、JSON 大小、图片大小与像素数均有上限，异常输入不能导致无界循环。

## 工作分工与接口

- [x] 页面与导航：`views/ToolsView.vue`、`App.vue`、`router/index.ts`，目录对应 `timestamp`、`qrcode`、`crypto`、`random`、`calculator`、`json`、`cron`、`radix`。
- [x] 共享控件：`components/tools/CopyButton.vue` 接收 `text: string`、可选 `label: string`，同时支持 Clipboard API 和 HTTP 下的复制回退；`styles/tools.css` 提供输入、按钮、结果与错误状态样式。
- [x] 时间与计划：`TimestampTool.vue` 双向秒/毫秒转换、本地/UTC；`CronTool.vue` 解析5/6字段表达式并预览未来10次；`RadixTool.vue` 在2/8/10/16进制间转换。
- [x] 二维码与加密：`QrCodeTool.vue` 支持中文生成、PNG下载、图片识别；`CryptoTool.vue` 提供对称加解密、RSA、摘要与Base64，明确格式和输入限制。
- [x] 日常开发工具：`RandomTool.vue` 支持范围、数量、精度、去重与排序；`CalculatorTool.vue` 安全解析表达式并接受键盘输入；`JsonTool.vue` 校验、格式化、压缩、JSON字符串序列化与反序列化。
- [x] README：记录入口、工具能力及浏览器本地处理方式，不添加个人环境配置。
