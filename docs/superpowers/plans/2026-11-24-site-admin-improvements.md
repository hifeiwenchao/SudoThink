# 网站与后台优化计划

**目标：** 落实代码审查中提出的稳定性、编辑恢复、查询性能、SEO、导航、回收站及提醒历史优化。

**约束：** 请求日志固定保留最近 7 天，不新增保留期限环境变量。发布方式保持不变。本次先在本地实现并验证，不操作远端业务数据。沿用 Vue/Sanic/Tortoise/Celery 与现有 Conda `sudothink` 环境。

## 方案与接口

- 登录：正确返回输入校验错误，统一清理内存与存储会话并跳转登录；保留站内返回路径。恢复内容按管理员、文章 ID 隔离，本地草稿不包含登录凭据；明确提供恢复或丢弃，不覆盖服务器内容。
- 列表：公共文章查询不读取/返回正文，详情保留正文。文章管理修复搜索重置页码、过期响应、加载失败重试，增加已发布/草稿/回收站筛选。
- 回收站：Article 增 `deleted_at` nullable；删除改为软删除，正文、标签、评论保留；所有公共入口拒绝回收文章，后台可列出/恢复。恢复保留原发布状态，不提供永久删除按钮。
  - `GET /api/admin/articles?status=all|published|draft|trash`
  - `POST /api/admin/articles/<id>/restore`
  - 列表响应含 `deleted_at`，默认 all 仅未删除记录。
- 首页：搜索、分类、标签、页码统一写 URL；返回/刷新恢复筛选及位置。
- SEO：各页面独立 title/description/canonical/OG，保持微信分享；新增站内公开 sitemap/robots 可抓取入口，排除草稿、回收站、管理站。不承诺动态 meta 对不执行 JavaScript 的抓取器完全生效，保持可后续接预渲染的边界。
- 日志：Celery 每小时分批清理严格早于当前时间减 7 天的记录；新增 `created_from`/`created_to` 带时区时间范围筛选，校验反向范围和非法值。
- 待办：新增归属管理员私有的提醒执行/失败/跳过历史；保留每次计划时间、实际记录时间、结果、脱敏错误，限定分页查询。`GET /api/admin/todos/<id>/history?page=1&size=20` 返回 `{items,total,page,size}`，条目字段 `{id,event,scheduled_at,created_at,next_run_at,error}`；event 为 sent/failed/skipped，历史随待办删除级联清理。提醒历史写入必须与版本状态更新一致，旧领取任务不得污染新计划。

## 执行任务

- [x] 后端文章/SEO：测试先行实现软删除、列表瘦身、筛选校验、恢复、公共入口隔离和 sitemap，升级脚本幂等加列。
- [x] 登录/编辑恢复：测试先行修复后端登录异常与前端会话同步、本地草稿自动保存和恢复交互。
- [x] 网站/文章管理：测试先行实现 URL 状态、SEO 和文章管理筛选/回收站恢复、搜索与错误状态。
- [x] 运维/待办：实现固定 7 天日志清理、日期筛选、提醒历史及对应后台界面，补真实数据库和组件测试。
- [x] 集成审查、全量前后端测试、生产构建与必要的浏览器交互检查；更新详细文档，README 仅保留关键部署信息。

## 重点验证

- 损坏/不可访问 localStorage、不合法登录请求、401 并发、登录页本身401不循环，错误消息不淹没界面。
- 编辑恢复不能跨账号读取，空白新建/初次服务端填充不产生草稿，成功保存清除对应草稿；重新登录整页跳转后可恢复。
- 回收文章不出现在首页、搜索、详情、评论、统计或 sitemap；恢复不改正文/原发布时间/关系。
- 日志恰好 7 天边界保留，分批重复执行安全；过滤保留稳定分页与参数严格校验。
- 待办失败自动重试逐次记录，跳过记录可查询；旧 SMTP 结果不生成成功历史，不记录私密邮箱/凭据。

验证结果：后端 371 项（350 通过、21 项外部 Redis 集成测试跳过），前端 263 项全部通过，生产构建通过。独立审查修复返回列表路径问题；实际浏览器检查了回收站恢复、提醒历史及 390px 卡片/日期筛选。两份 NGINX 配置在现有容器中以临时文件执行 nginx -t 通过，未替换配置或重载服务。临时预览服务和文件已清理，未部署。
