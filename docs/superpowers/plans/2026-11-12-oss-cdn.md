# OSS 上传与 CDN 接入实施计划

**目标：** 管理员可将本地图片、视频直传阿里云 OSS，正文和封面使用 CDN URL；生产构建的 JS/CSS 也可上传 OSS 并通过阿里云 CDN 分发。

**架构：** 后端从根目录 `.env` 读取 OSS 凭据，使用官方 OSS V4 PostObject 签名算法生成短期、限定对象键、类型、大小的直传表单。客户端使用独立上传请求，应用 JWT 只发送给应用 API。CDN 使用公共 HTTPS 资源域名，私有 Bucket 可按阿里云配置 CDN 私有回源授权。HTML 与 API 保持站点同源。

**范围：** 本地实现和验证，不修改线上服务或云资源，不提交或发布。媒体插入复用 HTML content，无数据库迁移；不添加转码、资源库或自动删除文件。已存在的外链保持原地址。

## 契约与默认值

- `GET /api/admin/uploads/config`：管理员鉴权，返回 `enabled`、`image_max_bytes`、`video_max_bytes`、`image_types`、`video_types`。未配置 OSS 时功能禁用，其他功能正常运行。
- `POST /api/admin/uploads/policy`：管理员鉴权，JSON `{filename, size, content_type}`；返回 `{upload_url, public_url, key, fields, expires_at}`。fields 包含 OSS V4 签名、精确 key / Content-Type / success_action_status=201 条件，file 最后加入。
- `.env`：`ACCESS_KEY_ID`、`ACCESS_KEY_SECRET`、可选 `OSS_SECURITY_TOKEN`；`OSS_REGION`、`OSS_BUCKET`、`OSS_ENDPOINT`；`CDN_BASE_URL`；`OSS_MEDIA_PREFIX=media`、`OSS_STATIC_PREFIX=static`；`OSS_IMAGE_MAX_BYTES=10485760`、`OSS_VIDEO_MAX_BYTES=209715200`；`VITE_ASSET_BASE_URL`（可留空，本地资源）。媒体扩展 PNG/JPG/JPEG/GIF/WebP/AVIF、MP4/WebM；OSS 签名有效期 5 分钟。
- 上传 key 服务端产生：`media/{images|videos}/YYYY/MM/{uuid}.{ext}`；URL 使用 CDN_BASE_URL。上传 MIME/后缀相符；大小正整数且不超配置；每份凭证仅允许该对象和声明大小。密钥不进入 VITE 变量、源码或日志。
- 前端 `uploadMedia(file, {signal, onProgress}) -> {url, key, kind}`；原生 XHR / FormData 向 OSS 发请求，支持取消、不附带应用 JWT。
- Tiptap video 作为 block atom，保存 `<video src=... controls preload=metadata playsinline>`；清洗只允许安全 HTTP(S)/站内 URL，无自动播放或可执行属性。纯视频文章算有效正文。
- 前端 Vite 生产 `base=VITE_ASSET_BASE_URL || '/'`；资源发布脚本验证 URL 与 CDN/prefix 一致、跳过 index.html、设置 MIME 与 immutable 缓存。文档强调先上传构建资源，再切换应用容器，保留旧版本资源。
